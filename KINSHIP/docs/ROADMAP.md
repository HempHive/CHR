# Roadmap

Status words mean what they say. "Designed" is not "implemented".

## Phase 1 — Foundation — implemented in 1.0

Application shell, IndexedDB, person and relationship editing, traditional tree, search, backup and restore, tests. See `PHASE1_REPORT.md`.

## Phase 2 — Genealogy — designed

Ancestor, descendant, hourglass, and radial trees on the same records. Relationship finder that states when a path is incomplete. Source records and citations. GEDCOM preview, import, and export. Richer research questions. Duplicate review already exists in a small form and should grow into a comparison screen, still without silent merges.

## Phase 3 — Photographs — designed

Batch import, originals preserved, thumbnails, metadata, manual regions, group photographs, life galleries, hash duplicates. See `MEDIA.md`.

## Phase 4 — Time and place — designed

Life explorer and family time machine that show unknown states instead of inventing them. Map of births, deaths, residences, and events with approximate places. Geocoding stays optional.

## Phase 5 — Multimedia — designed

Documents, audio with waveforms and transcripts, video, exhibitions, story studio. Presentation mode for a large screen. No automatic upload of recordings.

## Phase 6 — Advanced experience — designed

Constellation view with a reduced-motion alternative. Deeper search. Optional assistance that is labelled as generated and cannot commit a fact by itself. No face recognition in that work.

## Phase 7 — Release hardening — partly started

1.0 has tests, a backup path, and this documentation. Still ahead: large-archive performance, a fuller accessibility pass, restoration drills on copies, installation beyond the Vite dev server, and a versioned desktop build.

Each later phase should leave the app usable and should report what was implemented, what was only designed, and what was actually tested.
